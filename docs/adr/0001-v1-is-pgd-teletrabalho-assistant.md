# v1 is a Unifesp PGD telework assistant, not a generic knowledge platform

The repository is named as an enterprise RAG platform, but v1 answers only a Servidor's questions about currently effective Unifesp PGD telework (modalities, limits, in-person recall, and what is not a right). A generic multi-domain platform was rejected because grounding, freshness, and citations cannot be proven without one verifiable corpus; leave, reimbursement, contracts, and FAQ wait until the telework golden set passes.

**Status:** accepted
